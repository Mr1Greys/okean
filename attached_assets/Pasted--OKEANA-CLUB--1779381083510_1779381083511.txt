# ПРОМТ ДЛЯ РЕДИЗАЙНА

## ЗАДАЧА

Сделать полный редизайн сайта семейного клуба «Океана» (okeana.club). Сохранить существующую цветовую палитру и узнаваемость бренда. Главный приоритет — мобильная версия: она должна быть удобной, читабельной и вести пользователя к целевому действию (запись/звонок).

---

## ЦВЕТОВАЯ ПАЛИТРА (сохранить)

- **Основной акцент:** морской/бирюзовый (~`#1E9AB0` или близкий голубой)
- **Фон:** белый / светло-серый
- **Текст:** тёмно-серый / антрацит
- **Кнопки CTA:** насыщенный бирюзовый или коралловый акцент
- **Дополнительно:** мягкие пастельные оттенки (голубой, нежно-зелёный) для карточек и блоков

> Уточнить точные hex-коды через DevTools на текущем сайте. Не менять общую «водную» атмосферу.

---

## ТЕХНИЧЕСКИЙ СТЕК

**Рекомендация:** Next.js 14 (App Router) + Tailwind CSS + Framer Motion для анимаций  
**Почему:** SEO из коробки, быстрая загрузка, удобная работа с мобильной адаптацией через Tailwind breakpoints, компонентная архитектура для повторяющихся блоков (карточки программ, прайс-карточки)  
**Деплой:** Vercel  
**Форма обратной связи:** встроенная через Formspree или Telegram Bot Webhook  
**Карта:** Яндекс.Карты API (уже используется)

## ОБЩИЕ ТРЕБОВАНИЯ К ДИЗАЙНУ

### Навигация
- Мобильный header: логотип слева, телефон-кнопка по центру/справа, бургер-меню справа
- Бургер открывает full-screen drawer с крупными пунктами меню (min 48px touch target)
- Фиксированная шапка (sticky) с кнопкой «Записаться» всегда видна при скролле
- Desktop: горизонтальное меню с дропдаунами (О нас, Программы и цены)

### Типографика
- Мобильный заголовок H1: 28–32px, H2: 22–24px
- Межстрочный интервал: 1.5–1.6 для основного текста
- Шрифт: округлый, дружелюбный — Nunito, Rounded Mplus или Inter

### CTA-кнопки
- Минимум одна кнопка «Записаться» / «Заказать звонок» на каждом экране (мобиль)
- Плавающая кнопка звонка (FAB) на мобиле в правом нижнем углу: телефон или WhatsApp-иконка
- Размер кнопок: не менее 44×44px

## СТРАНИЦЫ — ДЕТАЛЬНЫЕ ТРЕБОВАНИЯ

### Главная страница
- **Hero-секция:** полноэкранный баннер с фото/видео бассейна, короткий заголовок, подзаголовок, 2 кнопки: «Записаться» + «Смотреть программы»
- **Преимущества:** 4–5 иконок-карточек горизонтальным скроллом на мобиле (тёплая вода, сертифицированные тренеры, индивидуальные кабинки, методика Birthlight, лаунж с чаем)
- **Программы:** карточки-плитки с иконкой, названием, возрастом, кнопкой «Подробнее»
- **Текущая акция:** выделенный баннер с акцией (10% + без вступительного взноса) — заметный, но не агрессивный
- **FAQ:** аккордеон (accordion) — компактно, без таблиц
- **Карта + контакты:** блок внизу с картой, адресом, телефоном, временем работы
- **Форма звонка:** модальное окно или inline-форма с 3 полями

### Страница «Цены» — КРИТИЧЕСКИЙ РЕДИЗАЙН

**Текущая проблема:** HTML-таблицы с множеством колонок (Программа / Кол-во / Срок / 30 мин / 45 мин / 60 мин) — на мобиле горизонтальный скролл или сломанная верстка, невозможно читать.

**Решение — карточная система:**

```
Структура страницы:
1. Табы/переключатель вверху: [Бассейн] [Зал]
2. Внутри «Бассейн» — второй переключатель: [Групповые] [Индивидуальные]
3. Каждая программа = отдельная карточка (card)
```

**Формат карточки программы (мобиль):**
```
┌─────────────────────────────────┐
│ 🏊 Детское плавание             │
│ Возраст: 0–10 лет • 45 мин     │
│                                 │
│ Пробное занятие    900 ₽       │
│ ─────────────────────────────  │
│ 4 занятия / 30 дней  6 390 ₽  │
│                      1 598 ₽/занятие │
│ 8 занятий / 30 дней  11 590 ₽ │
│                      1 449 ₽/занятие │
│ 10 занятий / 45 дней 13 590 ₽ │
│                      1 359 ₽/занятие │
│                                 │
│      [Записаться]               │
└─────────────────────────────────┘
```

- Карточки в 1 колонку на мобиле, 2–3 на десктопе
- Пробное занятие выделено отдельным бейджем/тегом «Первый раз»
- Стоимость за занятие — мелким текстом серого цвета под суммой абонемента
- Кнопка «Записаться» в каждой карточке → открывает форму с предзаполненным названием программы
- Блок с условием отмены — отдельным баннером внизу страницы

### Страница «Программы»

**Текущая проблема:** Контент представлен таблицами без описания, неинформативно.

**Решение:**
- Карточки программ с фото/иллюстрацией, названием, возрастом, кратким описанием (2–3 строки), ссылкой «Подробнее» и кнопкой «Записаться»
- Фильтр/табы: [Для детей] [Для взрослых] [Будущим мамам] [Спецпредложения]
- На мобиле — вертикальный список карточек

### Страница «Расписание»

**Текущая проблема:** Страница полностью пустая.

**Решение:**
- Недельная сетка с занятиями (вертикальный scroll на мобиле)
- Цветовая кодировка по типу: бассейн (голубой), зал (зелёный), особые (оранжевый)
- Фильтр по программе/тренеру
- При тапе на занятие — карточка с деталями и кнопкой «Записаться»
- Fallback: если расписание не ведётся онлайн — блок «Уточните расписание» с кнопкой звонка

## МОБИЛЬНАЯ ВЕРСИЯ — КРИТИЧЕСКИЕ ТРЕБОВАНИЯ

1. **Touch targets:** все интерактивные элементы ≥ 44×44px
2. **Таблицы цен:** полностью заменить на карточки (см. выше) — никаких горизонтальных таблиц
3. **Телефонный номер:** всегда кликабелен (`<a href="tel:+79771843409">`)
4. **Sticky CTA:** фиксированная кнопка «Записаться» или телефон внизу экрана
5. **Шрифт:** минимум 16px для основного текста (избегать zoom на iOS)
6. **Формы:** поля не мельче 16px, keyboard-friendly (type="tel" для телефона, type="email" для email)
7. **Изображения:** WebP, lazy loading, srcset для разных размеров экрана
8. **Аккордеоны вместо длинных текстов:** для FAQ, правил, условий
9. **Нет горизонтального скролла** нигде, кроме намеренных каруселей с явными dot-индикаторами
